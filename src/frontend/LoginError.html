無法取得登入身份 (Email)

系統無法安全偵測到您的 Google 帳號身份。這通常是由於瀏覽器未授權、使用了隱私瀏覽（無痕模式）或者網頁應用程式部署權限設定所導致的。

🛠️ 阻斷性診斷與部署調整建議：
  • 請勿在無痕模式或第三方 Cookie 被阻擋的瀏覽器環境中開啟此系統。
  • 系統管理員調整建議：請將 Web App 的部署設定變更為：
    將「執行為 (Execute as)」設為：存取網頁的使用者 (User accessing the web app)
    這將強制要求每個存取者在瀏覽時通過 Google OAuth 授權，即可順利讀取其 Email。
